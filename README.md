# Chirayu Mahajan — Portfolio

A dependency-free personal portfolio built with semantic HTML, CSS, and modern JavaScript. It is ready for static hosting on GitHub Pages—no build step or server is required.

## Local preview

Open `index.html` in a browser, or run a static file server from the repository root.

## Deploy to GitHub Pages

1. Create a GitHub repository and push these files to its `main` branch.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select `main`, then `/ (root)`, and save.
4. GitHub will publish the site at `https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/`.
5. Replace `YOUR-GITHUB-USERNAME` and `YOUR-REPOSITORY-NAME` in `robots.txt` and `sitemap.xml` with the published URL. Also update the LinkedIn, GitHub, email, and resume links in `index.html`.

## Included

- Responsive dark-first interface with persisted light mode
- Keyboard-accessible navigation, focus states, skip link, and reduced-motion support
- Scroll progress, reveal animations, counters, command palette (`Ctrl/Cmd + K`), mobile menu, and expandable experience details
- SEO metadata, OpenGraph image, JSON-LD, `robots.txt`, and sitemap
